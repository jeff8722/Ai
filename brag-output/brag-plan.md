# VESTIQ ad (brag-slim)

**What it is:** a virtual fitting room for clothing shops. A shopper takes one photo on the shop's tablet, picks real stock from the shop's catalogue, and sees themselves wearing it, without queuing for a trial room.
**For:** shoppers in the store (and the shops that run it).
**Sets it apart:** real catalogue garments on the shopper's own photo; outfits (top then bottoms); a scannable code so staff fetch the size; the photo is erased when the session ends.
**Visual hook:** the app's own hero: huge swing tags TRY / IT / ON. dropping onto a steel rail on red thread.
**Share caption:** see below (share-copy.txt).

**Tone:** `app-store`, warmed with the Hang-Tag world: clean feature beats, smooth slides, playful tag physics. **Format:** landscape 1920×1080, 30 fps. **Length:** 62 s (user asked for a 1–2 minute ad; brag's 15–25 s default overridden on purpose).

**Identity (from src/styles.css):** board #e2e6ea, woven black #161616 with stitch insets, red thread #d92128, tag stock cobalt #2a46d8 / fuchsia #d6307a / sun #ffc21f, Bricolage Grotesque 800 condensed, Libre Barcode 39.

**Truth rules:** every try-on picture is a real output of this project's model (`backend/test-images`: person + shirt → shirt_result, person + shirt + jeans → complete_outfit). No invented numbers, speeds or testimonials. Copy comes from the app.
